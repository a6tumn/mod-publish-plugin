## Basic example
<Tabs items={['Groovy', 'Kotlin']}>
  <Tab>
    ```groovy
    publishMods {
        file = jar.archiveFile
        changelog = "Changelog"

        hangar {
            accessToken = providers.environmentVariable("HANGAR_TOKEN")
            id = "ExampleProject"
            projectType = PAPER
            channelType = "Release"
            platformVersions.add("26.1.2")
        }
    }
    ```
  </Tab>
  <Tab>

    ```kotlin
    publishMods {

        changelog.set("Changelog")

        hangar {

            projectType.set(PAPER)

        }
    }
    ```
  </Tab>

## Parent releases
If you wish to upload files to a Hangar release created by another task either in the same project or another subproject, you can use the `parent` option.
This is useful where you have multiple subprojects that you want to publish to a single release, the following example shows how a root project can create the release and subprojects can upload files to it:

#### Root project
<Tabs items={['Groovy', 'Kotlin']}>
  <Tab>
    ```groovy
    publishMods {
        hangar {
            accessToken = providers.environmentVariable("HANGAR_TOKEN")
            id = "ExampleProject"
            projectType = PAPER
            channelType = "Release"
            platformVersions.add("26.1.2")

            // Allow the version to be initially created without any files.
            allowEmptyFiles = true // [NYI]
        }
    }
    ```
  </Tab>
  <Tab>
    ```kotlin
    publishMods {
        hangar {
            accessToken.set(providers.environmentVariable("HANGAR_TOKEN"))
            id.set("ExampleProject")
            projectType.set(PAPER)
            channelType.set("Release")
            platformVersions.add("26.1.2")

            // Allow the version to be initially created without any files.
            allowEmptyFiles.set(true) // [NYI]
        }
    }
    ```
  </Tab>
</Tabs>

#### Subproject
<Tabs items={['Groovy', 'Kotlin']}>
  <Tab>
    ```groovy
    publishMods {
        hangar {
            accessToken = providers.environmentVariable("HANGAR_TOKEN")

            // Specify the root project's Hangar task to upload files to
            parent project(":").tasks.named("publishHangar")
        }
    }
    ```
  </Tab>
  <Tab>
    ```kotlin
    publishMods {
        hangar {
            accessToken.set(providers.environmentVariable("HANGAR_TOKEN"))

            // Specify the root project's Hangar task to upload files to
            parent project(":").tasks.named("publishHangar")
        }
    }
    ```
  </Tab>
</Tabs>

## All options
<Tabs items={['Groovy', 'Kotlin']}>
  <Tab>
    ```groovy
    publishMods {
        hangar {
            accessToken = providers.environmentVariable("HANGAR_TOKEN")
            id = "ExampleProject"
            projectType = PAPER
            channelType = "Release"
            platformVersions.addAll("26.1", "26.1.1", "26.1.2)

            // Override the Hangar API endpoint.
            // Useful for testing or self-hosted environments.
            apiEndpoint = "https://hangar.papermc.io/api/v1/"

            // Upload the files to a previously created release, by providing another hangar publish task
            // This is useful in multi-project builds where you want to publish multiple subprojects to a single release
            parent tasks.named("publishHangar")
        }
    }
    ```
  </Tab>
  <Tab>
    ```kotlin
    publishMods {
        hangar {
            accessToken.set(providers.environmentVariable("HANGAR_TOKEN"))
            id.set("ExampleProject")
            projectType.set(PAPER)
            channelType.set("Release")
            platformVersions.addAll("26.1", "26.1.1", "26.1.2)

            // Override the Hangar API endpoint.
            // Useful for testing or self-hosted environments.
            apiEndpoint.set("https://hangar.papermc.io/api/v1/")

            // Upload the files to a previously created release, by providing another hangar publish task
            // This is useful in multi-project builds where you want to publish multiple subprojects to a single release
            parent tasks.named("publishHangar")
        }
    }
    ```
  </Tab>
</Tabs>
